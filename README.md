# Lambda Calculus β-Reduction Step Puzzle

Interactive step-by-step β-reduction puzzle trainer that validates each reduction manually entered by the user.

## Key Features

- 6 pre-built puzzles from simple identity/constant to SKI combinators, each requiring 1–5 validated reduction steps
- User selects the redex to reduce from radio options, then types the result; the app validates against the correct answer
- Green/red feedback with shake animation on incorrect answers; correct steps are shown in the step history
- Collapsible reference panel with Church numerals 0–3 and S, K, I combinator definitions plus the β-reduction rule
- Puzzle progress and selected puzzle persisted in localStorage
